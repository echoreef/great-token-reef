# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's
[private vulnerability reporting](https://github.com/echoreef/great-token-reef/security/advisories/new)
to send the details privately.

Include what you found, the steps to reproduce it, and the version or commit
you tested. You can expect an acknowledgement, and a fix or a decision on the
report as soon as the maintainer can manage it.

## Scope

Great Token Reef runs on your own machine and stores its data locally. It
reads Claude Code and Codex session logs, and keeps any GitHub and Jira
credentials in the macOS Keychain. Reports about how those credentials are
stored, sent or logged are especially welcome.
